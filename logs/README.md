# Research Logs

`logs/`는 **날짜별 연구 과정**을 기록하는 곳입니다.

권장 경로:

```text
logs/YYYY-MM/YYYY-MM-DD.md
```

각 일지에는 최소한 다음을 기록합니다.

- 오늘의 목표
- 수행 작업
- 실행 조건
- 결과
- 관찰
- 문제 / 의문
- 해석
- 다음 작업

실패한 실행도 원인과 수정 내용을 기록합니다.

## Chronology Rule

`logs/`의 핵심 목적은 **그날 무슨 일이 있었는지 시간 순서로 보존하는 것**이다.

따라서 다음 원칙을 지킨다.

- 과거 날짜의 작업을 오늘 날짜 log에 합쳐서 덮어쓰지 않는다.
- 과거 작업을 뒤늦게 정리할 때도 실제 작업 날짜의 파일을 생성하거나 수정한다.
- 이후 판단이 바뀌어도 당시 판단은 지우지 않고, 변경된 날짜의 log에 왜 바뀌었는지 기록한다.
- 오늘의 log에는 오늘 새로 수행한 작업, 관찰, 실패, 판단만 추가한다.
- 여러 날짜에 걸친 실험의 최종 정리는 `experiments/` README에서 수행하고, `logs/`는 날짜별 흐름을 유지한다.

즉:

```text
logs/        = 시간 순서 기록
experiments/ = 연구 논리 순서 기록
```

두 기록을 함께 봤을 때 **언제 무엇을 했는지**와 **왜 다음 실험으로 넘어갔는지**를 모두 추적할 수 있어야 한다.
